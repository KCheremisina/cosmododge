# CosmoDodge

Простая аркадная игра на уклонение от астероидов

## Описание

CosmoDodge - это минималистичная браузерная аркада, созданная на библиотеке PixiJS. Игрок управляет космическим кораблём и должен уклоняться от падающих астероидов. С каждым пройденным астероидом сложность постепенно увеличивается. Проект представляет собой чистый JavaScript без использования игровых движков.

### Жанр и тип
- Жанр: Аркада / Dodge
- Тип: 2D Browser Game
- Перспектива: Top-down (вид сверху)
- Стиль: Минималистичная векторная графика

## Технологии

**Основные технологии:**
- PixiJS - 2D рендеринговая библиотека для WebGL
- JavaScript (97.2% кода проекта) - язык программирования
- HTML (2.8%) - разметка страницы
- localStorage - для сохранения рекордов

**Архитектурные паттерны:**
- Объектно-ориентированный подход - классы для игровых сущностей
- Object Pooling - пул частиц для оптимизации производительности
- Конфигурация через объект CONFIG - централизованное хранение настроек
- Event-driven ввод - обработка клавиатуры и мыши/тача

## Реализованные фичи

**Основные механики геймплея:**

1. **Управление кораблём**
   - Управление клавиатурой (WASD или стрелки)
   - Управление мышью/тачем (корабль следует за курсором)
   - Плавное движение с интерполяцией
   - Корабль поворачивается в направлении движения
   - Ограничение движения границами экрана

2. **Система астероидов**
   - Процедурная генерация астероидов сверху экрана
   - Разные размеры и скорости вращения
   - Постепенное увеличение скорости падения
   - Увеличение частоты появления со временем
   - Удаление астероидов после выхода за экран

3. **Система очков**
   - Начисление очков за каждый успешно пройденный астероид
   - Отображение текущего счёта в реальном времени
   - Сохранение лучшего результата в localStorage
   - Отображение рекорда на экране

4. **Система сложности**
   - Прогрессивное увеличение сложности
   - Каждые N очков повышается уровень сложности
   - Увеличение скорости падения астероидов
   - Увеличение частоты спавна новых астероидов
   - Максимальные ограничения на скорость и частоту

5. **Визуальные эффекты**
   - Частицы двигателя корабля (ParticlePool)
   - Эффект взрыва при столкновении
   - Звёздное поле на фоне (Starfield)
   - Анимация вращения астероидов
   - Плавные переходы между состояниями игры

6. **Пользовательский интерфейс**
   - Экран начала игры с подсказкой
   - Отображение текущего счёта
   - Отображение лучшего результата
   - Экран Game Over с финальным счётом и рекордом
   - Кнопка перезапуска после проигрыша

7. **Система состояний игры**
   - Start - ожидание начала игры
   - Playing - активная игра
   - Over - конец игры
   - Автоматический старт при нажатии клавиши/клика

**Технические особенности:**
- requestAnimationFrame через Pixi Ticker для игрового цикла
- Delta time для независимости от FPS
- Object pooling для частиц (оптимизация памяти)
- Canvas-based рендеринг через WebGL
- Responsive дизайн с обработкой resize
- Pointer events для поддержки мыши и тач-устройств
- Collision detection через проверку расстояния между кругами

## Запуск проекта

**Локальный запуск:**
- Установите зависимости: `npm install`
- Запустите локальный сервер: `npm start` или откройте index.html в браузере
- Игра запустится автоматически

**Требования:**
- Современный браузер с поддержкой WebGL
- Не требуется установка дополнительных программ

## Управление

- **WASD / Стрелки** - движение корабля
- **Мышь / Тач** - корабль следует за курсором
- **Любая клавиша / Клик** - начать игру
- **Клик после Game Over** - перезапустить игру
